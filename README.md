A mod fork of “[Create Firearms Patch](https://www.curseforge.com/minecraft/mc-mods/create-firearms-patch)” by “[JEDIGD](https://www.curseforge.com/members/jedigd/projects)” for version 1.21.1, in which the mechanics have been partially reworked.

ChatGPT helped me write the code, but the new textures and logic are entirely my own work. If you find any bugs or have any suggestions, please let me know in the GitHub comments.


# Installation Instructions

Please note: Kinetic-pixel does not include weapons; they must be downloaded separately

1. Download Vic's Point Blank.
2. Move the kp-ext.zip file to the “pointblank” folder located in the game's root directory (if the “pointblank” folder does not exist, create it).
